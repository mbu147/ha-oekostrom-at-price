# Oekostrom AT Price

A Home Assistant custom component to fetch and display the Oekostrom AT energy price.

## Installation

1. Add the repository to HACS by adding this URL: `https://github.com/mbu147/ha-oekostrom-at-price`
2. Install the "Oekostrom AT Price" integration via HACS.
3. Add the integration through the Home Assistant UI.

## Configuration

Go to the Home Assistant UI, navigate to "Configuration" -> "Integrations" and add the "Oekostrom AT Price" integration. Enter your login credentials for `mein.oekostrom.at`.

## Usage

The integration will create a sensor in Home Assistant that displays the current energy price from `mein.oekostrom.at`.
